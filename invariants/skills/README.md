# Skills Invariants

These documents capture the current invariant surface for the `skills` feature as implemented in this repo today.

## Scope

- Skills are file-backed expertise modules loaded into agent context.
- This directory records current constraints that already shape the implementation.
- Planned expansion should extend these documents instead of replacing current behavior with unstated assumptions.

## Current invariant set

- `discovery.md` defines where skills come from and how they are identified.
- `runtime.md` defines what loading a skill must provide to the runtime and current user-facing boundaries.
