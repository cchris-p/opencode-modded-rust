# V3

## Goal

Expand from a narrow daily-driver into a broader and more complete local coding environment.

## Why this version exists

V3 exists to close the biggest practical workflow gaps discovered through real use in V1 and V2.

## Required capabilities

- broaden the useful feature set from the current OpenCode reference line
- close major workflow gaps discovered during V1 and V2 usage
- improve ergonomics without weakening the runtime architecture
- selectively adopt capabilities only when they improve real usage

## Explicit non-goals

- blanket parity for parity's sake
- feature uptake without demonstrated personal-use value

## What V3 adds beyond V2

- wider daily-use workflow coverage
- selective adoption of high-value reference capabilities
- stronger ergonomics for regular use
- more complete repository intelligence where it improves real task execution

## What is still missing after V3

- any intentionally deferred surfaces such as desktop, MCP, or broad distribution
- optional ecosystem work that does not materially improve the core product

## Success gate

V3 succeeds when the Rust runtime becomes the default local coding agent for everyday use across a wider set of workflows.

## Dependencies

- V3 should be driven by actual usage gaps rather than abstract completeness goals.
