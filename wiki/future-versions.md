# Future Versions

These versions remain intentionally less specific than V1 through V3, but they should still identify the major capability areas that later work may need.

## Required capability areas

- selective upstream feature review
- richer repository graph capabilities
- broader provider and deployment surfaces
- more advanced agent evaluation inside the Rust product
- later consideration of distribution, packaging, or ecosystem expansion

## Possible later-version additions

- broader autonomous orchestration once the core runtime is trusted
- mature graph-driven retrieval and planning
- richer interfaces beyond the TUI
- carefully selected ecosystem integrations

## Intentionally deferred for now

- desktop app
- MCP
- other non-core surfaces currently tracked as future board work

## What these versions assume is already complete

- V1-level personal daily-driver viability
- V2-level reliability improvements
- V3-level broader workflow usefulness
